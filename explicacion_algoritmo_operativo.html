📊 Algoritmo Operativo de Trading

Explicación detallada con ejemplos visuales

1

Parámetros de Entrada

El algoritmo requiere configurar estos parámetros antes de calcular las señales:

n (Período)
Valor: 20 o 50 (tomado del Período WAM)
Número de elementos para el promedio móvil ponderado. Se recomienda usar 50 para mejor precisión.
pt (Parámetro de Tendencia)
Valor predeterminado: 0.30
Umbral para establecer si existe tendencia. Si RP± ≥ pt, entonces existe tendencia.
pr (Parámetro de Rompimiento)
Valor predeterminado: 0.75 (75%)
Porcentaje para detectar rompimiento de tendencia. Si RP⁻/RP⁺ ≥ pr o RP⁺/RP⁻ ≥ pr, hay rompimiento.
σ (Sigma)
Valor predeterminado: 2.0
Multiplicador de desviación estándar para validar señales. Controla la precisión de las condiciones de entrada.
mp (Importe Inicial)
Valor predeterminado: €1000
Importe inicial para acumulación de operaciones en tendencia.
fd (Factor Decreciente)
Valor predeterminado: 0.95
Factor para reducir el importe en operaciones sucesivas. IMPi = mp × (1 - fd)i-1
2

Cálculo de Máximo y Mínimo (PMPn)

El Promedio Móvil Ponderado PMPn se calcula para el máximo y mínimo de los últimos n elementos:

CUANDO i = 1 (primer elemento):
P₁ = Pᵢ = PMPnᵢ = max(P) = min(P)
PARA i > 1 (elementos siguientes):
Si PMPnᵢ ≥ max(P) entonces max(P) = PMPnᵢ
Si PMPnᵢ ≤ min(P) entonces min(P) = PMPnᵢ
📌 Ejemplo Práctico:

Tenemos precios de EURUSD:

i Precio (Pᵢ) PMPnᵢ max(P) min(P)
1 1.08450 1.08450 1.08450 1.08450
2 1.08520 1.08485 1.08485 1.08450
3 1.08600 1.08550 1.08550 ✓ 1.08450
4 1.08430 1.08400 1.08550 1.08400 ✓

✓ indica cuando max(P) o min(P) se actualiza con el nuevo PMPnᵢ

3

Cálculo de Rangos Primarios (RP⁺ y RP⁻)

Los rangos primarios miden la distancia entre el PMPn actual y los extremos históricos:

RANGO PRIMARIO POSITIVO (RP⁺):
RP⁺ = |PMPnᵢ - min(P)|
Ejemplo RP⁺:
PMPnᵢ = 1.08550
min(P) = 1.08400
RP⁺ = |1.08550 - 1.08400| = 0.00150
RANGO PRIMARIO NEGATIVO (RP⁻):
RP⁻ = |max(P) - PMPnᵢ|
Ejemplo RP⁻:
max(P) = 1.08600
PMPnᵢ = 1.08550
RP⁻ = |1.08600 - 1.08550| = 0.00050
4

Detección de Tendencia

La tendencia se establece comparando los rangos primarios con el parámetro pt:

↗ TENDENCIA AL ALZA
RP⁺ ≥ pt
Ejemplo:
RP⁺ = 0.00150
pt = 0.30
Resultado: 0.00150 ≥ 0.30 ✓
↘ TENDENCIA A LA BAJA
RP⁻ ≥ pt
Ejemplo:
RP⁻ = 0.00050
pt = 0.30
Resultado: 0.00050 ≥ 0.30 ✓
⚠️ Detección de Rompimiento de Tendencia:
Rompimiento al alza: RP⁻ / RP⁺ ≥ pr
Rompimiento a la baja: RP⁺ / RP⁻ ≥ pr

Cuando se detecta un rompimiento, se actualiza:
Al alza: min(P) = PMPnᵢ
A la baja: max(P) = PMPnᵢ

5

Separación entre PMPn y Precio (Difn)

La separación mide qué tan lejos está el precio actual del PMPn:

FÓRMULA DE SEPARACIÓN:
Difnᵢ = (|PMPnᵢ - Pᵢ|)
PROMEDIO DE SEPARACIONES:
Prom Difnᵢ₋₁ = Σⱼ₌₁ⁱ⁻¹ Difnⱼ / (i - 1)
DESVIACIÓN ESTÁNDAR:
σDifnᵢ₋₁ = σ{Difn₁, Difn₂, ... Difnᵢ₋₁}
📌 Ejemplo de Cálculo:
i PMPnᵢ Pᵢ Difnᵢ Prom Difn σDifn
1 1.08450 1.08450 0.00000 — —
2 1.08485 1.08520 0.00035 0.00000 —
3 1.08550 1.08600 0.00050 0.00018 0.00025
4 1.08400 1.08430 0.00030 0.00028 0.00021
6

Condiciones para Emisión de Señales

Se emite una orden cuando se cumplen LAS 4 CONDICIONES simultáneamente:

🟢 SEÑAL DE COMPRA
Condición 1: Existe tendencia al alza
RP⁺ ≥ pt
↓
Condición 2: PMPn alcanza el máximo
PMPnᵢ = max(P)
↓
Condición 3: PMPn cambió respecto al anterior
PMPnᵢ ≠ PMPnᵢ₋₁
↓
Condición 4: Separación dentro del rango esperado
Difnᵢ ≤ Prom Difnᵢ₋₁ ± 2σDifnᵢ₋₁
↓
✅ TODAS CUMPLIDAS → EMITIR ORDEN DE COMPRA
🔴 SEÑAL DE VENTA
Condición 1: Existe tendencia a la baja
RP⁻ ≥ pt
↓
Condición 2: PMPn alcanza el mínimo
PMPnᵢ = min(P)
↓
Condición 3: PMPn cambió respecto al anterior
PMPnᵢ ≠ PMPnᵢ₋₁
↓
Condición 4: Separación dentro del rango esperado
Difnᵢ ≤ Prom Difnᵢ₋₁ ± 2σDifnᵢ₋₁
↓
✅ TODAS CUMPLIDAS → EMITIR ORDEN DE VENTA
7

Cálculo del Importe de Acumulación

El importe para cada operación decrece con el tiempo según la fórmula:

FÓRMULA DEL IMPORTE:
IMPi = mp × (1 - fd)i-1

Donde:
• mp = importe inicial (ej: €1000)
• fd = factor decreciente (ej: 0.95)
• i = número de operación en la tendencia
📌 Ejemplo de Acumulación:

Parámetros: mp = €1000, fd = 0.95

Operación (i) Cálculo IMPi
1 1000 × (1 - 0.95)0 €1000.00
2 1000 × (1 - 0.95)1 €50.00
3 1000 × (1 - 0.95)2 €2.50
4 1000 × (1 - 0.95)3 €0.13

⚠️ El importe decrece rápidamente, reduciendo el riesgo en operaciones sucesivas hasta llegar a €1 (mínimo).
