📖 Leyenda de Columnas
PMPn: Promedio móvil ponderado del máximo o mínimo (usa el período WAM: 20 o 50)
RP+ / RP-: Rango primario (|PMPn - min/max(P)|)
Difn: Separación entre PMPn y precio actual
σDifn: Desviación estándar de las separaciones
IMPi: Importe de acumulación = mp × (1-fd)i-1
Señal: Se genera cuando se cumplen las 4 condiciones
✅ Condiciones para Emisión de Señales
🟢 COMPRA (cuando se cumplan las 4):
  1. Existe tendencia al alza (RP+ ≥ pt)
  2. PMPn = max(P)
  3. PMPn ≠ PMPn-1
  4. Difn ≤ Prom Difn-1 ± 2σDifn-1
🔴 VENTA (cuando se cumplan las 4):
  1. Existe tendencia a la baja (RP- ≥ pt)
  2. PMPn = min(P)
  3. PMPn ≠ PMPn-1
  4. Difn ≤ Prom Difn-1 ± 2σDifn-1
